# Phase 3 独立评测集

这是 Phase 3 质量修复后新增的合成场景集，共 10 例：

- 多故障正例 3 例：轴承磨损 + 传感器漂移、 不对中 + 润滑不良、 轴承磨损 + 通讯误报；
- 传感器 2 例：量程饱和、采样缺口；
- 机械单故障 2 例：不对中、润滑不良；
- 单故障负例 2 例：轴承磨损（温升是同一故障后果）、仅温度漂移（其余测点正常）；
- 数据不足负例 1 例：遥测不可用，必须转人工，不得推断多故障。

用途与边界：

1. 本集只用于 Phase 3 修复完成后的**单次**真实模型复验；不参与 Prompt 迭代调参。
2. 场景数据为合成数据，不代表真实厂商阈值；模型上下文只接收场景遥测、报警、MES 与手册，
   不接收 `case_id` 或 gold。
3. 如果单次复验失败，记录失败原因，不反复针对本集调 Prompt；后续泛化证据应来自新的场景。
4. 本集阈值低于原 50 例回归门槛，是因为它是小样本独立复验，不替代原回归门禁。
