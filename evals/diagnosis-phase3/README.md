# Phase 3 独立评测集

这是 Phase 3 质量修复后新增的合成场景集，共 10 例：

- 多故障正例 3 例：轴承磨损 + 传感器漂移、 不对中 + 润滑不良、 轴承磨损 + 通讯误报；
- 传感器 2 例：量程饱和、采样缺口；
- 机械单故障 2 例：不对中、润滑不良；
- 单故障负例 2 例：轴承磨损（温升是同一故障后果）、仅温度漂移（其余测点正常）；
- 数据不足负例 1 例：遥测不可用，必须转人工，不得推断多故障。

用途与边界：

1. 本集最初按“独立复验集”设计，但 Phase 3 调试期间，报告层、`mul-align-lube`、
   `mul-bearing-drift` 等用例被用于定位和修复具体缺陷。因此它现在是**已调试的开发集**，
   不能作为未触碰的 holdout 或泛化证据；case 文件里的 `split: "holdout"` 只是评测器
   的字段，不改变这一事实。
2. 场景数据为合成数据，不代表真实厂商阈值；模型上下文只接收场景遥测、报警、MES 与手册，
   不接收 `case_id` 或 gold。
3. 最终 10 例真实模型复验因 Provider HTTP 402 为 `NOT_RUN`；后续泛化证据必须来自新的、
   未参与调试的场景集，不能把本集定向 PASS 外推为泛化能力。
4. 本集阈值低于原 50 例回归门槛，是因为它是小样本开发集，不替代原回归门禁。
